# Project Glossary

| Term | Working definition | Confirmation needed |
|---|---|---|
| Onboarding request | A tracked request to add a router to the managed network process | Owner and required fields |
| Router | Network device represented by the request and related records | Identity and uniqueness rule |
| Process owner | Person accountable for the workflow definition and acceptance criteria | Name/role |
| Validator | Role that checks completeness and evidence | Permission scope |
| Technical reviewer | Role that evaluates technical suitability | Approval boundary |
| Security reviewer | Role that evaluates security and policy impact | Approval boundary |
| Execution record | Evidence-backed record of implementation activity and outcome | Manual/integrated scope |
| Audit event | Immutable record of a state change, decision, assignment, or sensitive action | Retention and access |
| Terminal state | State from which no normal transition continues without reopening | Per-process list |
| Offline bundle | Transferable package containing image, dependencies, metadata, checksums, and instructions | Format and transfer medium |
| Air-gapped environment | Target environment without internet access during installation or runtime | Network policy |
